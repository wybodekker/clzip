# clzip

remove common files in two zip archives from the first

## Properties

|key|value|
|-:|:-|
|  script:|clzip|
|   short:|remove common files in two zip archives from the first|
|    type:|bash|
|  author:|Wybo Dekker|
|   email:|[wybodekker@me.com](mailto:wybodekker@me.com)|
| version:|1.07|
| license:|GNU General Public License|
|   intro:|clzip removes files that are common in two zip archives|
|         |from the first archive. This may be useful if you make|
|         |full backups from time to time: many files that occur in|
|         |the first backup will also occur in following backups.|

## Options

|option|description|
|:-|:-|
|-h,--help	|print this help and exit|
|-H,--Help	|print full documentation via less and exit|
|-V,--version	|print version and exit|
|-d,--dry	|do a dry run, keeping temporary files|
